Self-hosted webfonts for iwang-1.github.io.

These four .woff2 files are COMMITTED build artifacts, not sources. They are
generated by scripts/subset-fonts.mjs from the @fontsource-variable/* npm
packages and are checked in deliberately: GitHub Actions runs only the fact gate
and `npm run build`, and the subsetter needs Python fontTools, which is not (and
should not become) a dependency of this repo. CI ships these bytes; it never
regenerates them. Re-run the subsetter after changing the rendered character
repertoire or bumping either font package. The cut is reproducible: it pins
SOURCE_DATE_EPOCH, so an unchanged input regenerates byte-identical files and a
font diff always means a real change.
