FIG. 01 · parallax-kv

Distributed systems in Go

parallax-kv (opens in new tab)

A three-node Raft key-value store built from scratch: PreVote, ReadIndex, persist-before-send ordering, snapshots, a durable WAL, a gRPC runtime.

GoRaftgRPCPorcupinedeterministic simulation

A deterministic stress harness ran 2.9 million client operations through partitions, crashes, message loss, delays, and snapshot churn. Zero safety violations, and zero Illegal verdicts from the linearizability checker. Proposing queued writes together cut WAL fsyncs from 2.23 to 0.46 per write, and raised durable throughput at 64 clients from 102 to 1,408 writes per second. Production log compaction keeps each node at about 1.3 MB on disk instead of 11.5 MB.

FIG. 02 · accretion-db

Storage engine in Rust

accretion-db (opens in new tab)

An embeddable LSM-tree storage engine: CRC-framed WAL, group commit, memtables, block SSTables, bloom filters, size-tiered compaction. The crate root forbids unsafe code, so the engine has no unsafe blocks by construction.

RustLSM treegroup commitcrash consistencyproptest

Fault-injection and property tests confirm that acknowledged writes survive simulated crashes, and that multi-key write batches are all-or-nothing at every crash point. Index-seeking range scans cut per-scan p50 from 22.4 ms to 0.26 ms. Benchmarked against sled, which wins every matched comparison on this host. Reported rather than omitted.

FIG. 03 · lodestone

Vector search in Rust

lodestone (opens in new tab)

A vector search engine built from scratch in Rust for embeddings and RAG retrieval. An HNSW proximity graph and an IVF-PQ compressed index sit over hand-written AVX-512 and ARM NEON distance kernels with runtime feature dispatch.

RustHNSWIVF-PQAVX-512 & NEON SIMDRAG retrieval

On 50,000 128-dimensional vectors on a single core, HNSW reached 0.976 recall@10 at about 31,800 queries per second, about 33x the exact brute-force search at that recall, and 9 to 33x across the 90%+ recall band. The baseline is the honest catch: it runs in parallel across all 48 vCPU while the search runs on one, so the two sides of that ratio are not core-for-core. On Apple Silicon, the NEON kernels run 6 to 12 times faster per distance call than scalar code, and both index types reload from checksummed files in under 100 ms instead of seconds of rebuilding.

More projects

RelayBench (opens in new tab)

An execution lab for tool-using AI agents. It runs agents against injected faults, such as a reservation that succeeds but reports a timeout, and compares two policies on the same inventory, request, and fault. Every run can be replayed deterministically and inspected decision by decision.

With a timeout that hides a committed write, a blind-retry policy double-books the reservation in 12 of 12 seeds, while a reconcile-first policy passes all 12. All 72 recorded runs replay exactly.

PythonAI agentsfault injectiondeterministic replay

Spillway Join (opens in new tab)

An external-memory inner equijoin in Rust that holds to a fixed build-memory budget: it partitions both inputs, recurses, and falls back to bounded blocks for skewed keys. Every output is checked row for row against SQLite.

Choosing the partition fanout from the data, instead of a fixed 16, cut median end-to-end time on a 100,000-row join from 1.227 s to 0.468 s, about 2.6x faster.

BatchWindow (opens in new tab)

A trace-driven simulator for deadline-aware inference batching. It compares single-request, FIFO, and deadline-aware policies, and on small traces measures each one's gap from an exact offline optimum.

On the recorded burst trace, deadline-aware batching left 4 of 12 requests late, against all 12 for FIFO batching, while using 30% less device time.

Pythonschedulinginference serving

LeasePost (opens in new tab)

A durable single-host job queue on SQLite with fenced leases: a worker that pauses past its lease cannot publish a result after a replacement has finished the job. Tests race concurrent claims and kill real worker processes.

A recorded contention run validated 256 job histories across eight worker processes, and eight racing redrives of one dead job extend its attempts exactly once.

PythonSQLiteleasescrash recovery

MinuteLedger (opens in new tab)

Event-time window aggregation that accepts corrections and deletions after a window has been published, and records each revision in a durable changelog that consumers replay from a checkpoint.

600 seeded updates match an independent offline computation, and 40 trials that crash it twice before chosen database writes all recover to the uninterrupted result.

TestTrail (opens in new tab)

Given two Git revisions of a Python project, selects the tests a change could reach through imports and prints the shortest import path that explains each selection. It is meant to order a fast first CI lane; the full suite stays the merge gate, since static import analysis cannot see every dependency.

On faults injected into a real project, it selected all five failing test pairs out of six and skipped the one that passed.
